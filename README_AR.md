# مشروع Zainab
مشروع أندرويد أولي باسم Zainab باستخدام Kotlin وJetpack Compose.

## الموجود في هذه النسخة
- واجهة عربية أولية.
- تبويبات للرئيسية والدول والمكالمات والرسائل والإعدادات.
- قائمة دول تجريبية.
- لا توجد أرقام هاتف حقيقية أو مكالمات أو رسائل فعلية في هذه النسخة.

## ملاحظة مهمة
لتفعيل أرقام حقيقية، يلزم مزود اتصالات يدعم الأرقام والمكالمات والرسائل. تحفظ مفاتيح API السرية على خادم آمن، وليس داخل التطبيق.

## البناء
افتح المجلد في Android Studio أو بيئة متوافقة مع Gradle، وانتظر مزامنة Gradle، ثم اختر Build > Build APK(s).
